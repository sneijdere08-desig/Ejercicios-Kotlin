# Ejercicios de Kotlin y POO

Sneijder Anguiano Estrada

**Descripción:** Repositorio con ejercicios prácticos sobre los fundamentos de programación y Programación Orientada a Objetos (POO) en Kotlin.

## Lista de ejercicios incluidos

### Bloque 1. Fundamentos de Kotlin
1. `Ejercicio01.kt` - Información de un usuario (Variables y tipos de datos)
2. `Ejercicio02.kt` - Calculadora de almacenamiento (Operadores aritméticos y tipos numéricos)
3. `Ejercicio03.kt` - Registro de una compra dentro de una aplicación (Entrada de datos y operaciones)

### Bloque 2. Estructuras de control
4. `Ejercicio04.kt` - Validación de acceso a una aplicación (Condicionales if y else)
5. `Ejercicio05.kt` - Menú de configuración de una aplicación (Estructura when)
6. `Ejercicio06.kt` - Control de intentos de inicio de sesión (Ciclo while)
7. `Ejercicio07.kt` - Consumo de batería (Ciclo for y acumuladores)

### Bloque 3. Funciones
8. `Ejercicio08.kt` - Calculadora mediante funciones (Funciones, parámetros y retorno)
9. `Ejercicio09.kt` - Validación de información de registro (Funciones y valores booleanos)

### Bloque 4. Programación Orientada a Objetos
10. `Ejercicio10.kt` - Primera clase y creación de objetos (Clases, propiedades y objetos)
11. `Ejercicio11.kt` - Constructores (Constructor primario)
12. `Ejercicio12.kt` - Encapsulamiento (Modificadores de acceso y protección de propiedades)

### Bloque 5. Principios de POO
13. `Ejercicio13.kt` - Herencia de dispositivos (Herencia)
14. `Ejercicio14.kt` - Polimorfismo en notificaciones (Sobrescritura de métodos)
